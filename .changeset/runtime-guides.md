The packaged docs add four how-to guides, one per runtime: verify from a browser (with a bundler or a CDN import map), from Node.js (keys from the environment, a logger, events, and `checkStatus()` from a job queue, with notes for Deno and Bun), from an edge function (submit in one request, resume in later ones), and from CI with the CLI (dry run, `--json` and `jq`, exit codes in a shell `case`, keys from CI secrets). Issue: https://github.com/aelmanaa/explorer-verify/issues/105
